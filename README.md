# 🏋️‍♂️ Sistema de Gerenciamento de Treinos

Aplicação desenvolvida para gerenciar treinos pessoais, permitindo o controle de alunos, exercícios e rotinas de treino de forma organizada.

---

## 🚀 Funcionalidades

* ✅ Criar treinos personalizados
* 👀 Visualizar treinos cadastrados
* ✏️ Atualizar informações dos treinos
* ❌ Remover treinos
* 🧑‍💼 Gerenciar alunos
* 💪 Gerenciar exercícios

---

## 🛠️ Tecnologias utilizadas

* Python
* (adicione aqui se usou mais: SQLite, Flask, etc.)

## ⚙️ Instalação e execução

Siga os passos abaixo para rodar o projeto localmente:

### 1. Clone o repositório

```bash
git clone https://github.com/TalesGab/Projeto-de-Algoritmos-Treinos-.git
```

### 2. Acesse a pasta do projeto

```bash
cd Projeto-de-Algoritmos-Treinos-
```

### 3. Crie um ambiente virtual

```bash
python -m venv .venv
```

### 4. Ative o ambiente virtual

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux/Mac:**

```bash
source .venv/bin/activate
```

### 5. Instale as dependências

```bash
pip install -r requirements.txt
```

### 6. Execute o projeto

```bash
python main.py
```
